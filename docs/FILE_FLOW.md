# StudySathi — File Flow & Replacement Guide

## GitHub repository structure

StudySathi/
├── README.md
├── docs/
│   ├── FILE_FLOW.md
│   ├── STEP1_CHECKLIST.md
│   └── ROADMAP.md
└── app/
    └── src/
        └── main/
            ├── AndroidManifest.xml
            ├── java/com/studysathi/app/MainActivity.kt
            └── res/
                └── values/strings.xml

## Upload rule
For Step 1, upload folders/files using the exact paths above.

## Replacement rule
Never replace the whole repository with a ZIP unless explicitly instructed.
When a future step says "replace", replace ONLY the named file/folder.

Example:
If Step 3 says:
app/src/main/java/com/studysathi/app/MainActivity.kt → REPLACE
then replace that file only.

## New-file rule
If a future step says "ADD":
create the exact folder path and upload the new file there.

## GitHub mobile flow
1. Open repository.
2. Add file → Create new file OR Upload files.
3. Create the exact folder path by typing it into the filename field.
4. Commit changes.
5. Do not rename files unless instructed.

## Android Studio flow
1. Open the StudySathi Android project.
2. Keep the existing Gradle/project files generated by Android Studio.
3. Replace only files specifically listed for each phase.
4. Sync/Build after each phase.
