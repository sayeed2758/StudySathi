# StudySathi Android — Step 3

## Replace/Add flow
- This Android folder supersedes the previous Step 2 `android` folder.
- Keep the web root files separate.

## Test
1. Open this `android` folder in Android Studio.
2. Build and install.
3. Open StudySathi.
4. Select one or more launchable apps.
5. Enable StudySathi in Accessibility settings.
6. Turn Focus Mode on.
7. Open a selected app.
8. StudySathi should return to its focus screen.

This is an exhibition prototype. Before any public release, review current Android and Google Play requirements for AccessibilityService usage and user disclosure.
